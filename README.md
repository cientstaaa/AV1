# AV1 Project

nesse projeto é mostrado pessoas e momentos históricos
na história da população brasileira, mostrando como a literatura
é importante para chegarmos nos dias atuais.

Temos 3 páginas, em que na primeira temos um formulário para receber
mais noticias sobre temas interessantes. 
Na segunda, um pouco sobre a fase do modernismo no Brasil e alguns 
nomes importantes.
Na terceira, um pouco mais afundo sobre alguns nomes históricos
na época do modernismo, durante suas 3 fases
